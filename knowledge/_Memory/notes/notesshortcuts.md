# Notes & Tasks Shortcuts Cheat Sheet

## 1. Notes & Knowledge Base Commands (`knowledge/_Memory/notes/`)
* **`ns`** — Show this shortcuts cheat sheet
* **`ne`** — Fuzzy-find and open any markdown note in `$EDITOR`
* **`ng <query>`** — Search all notes for `<query>` using ripgrep
* **`nt`** — Fuzzy-find notes and extract uncompleted action items (`- [ ]`)

## 2. Todo & GTD CLI Commands (`tasks/`)
* **`task`** or **`todo list`** — Display priority-sorted list of active tasks
* **`t`** — Clear screen, show today's date, and display active tasks
* **`n`** — Print the single next immediate action
* **`tg <query>`** — Search across all task markdown files with ripgrep
* **`ei`** — Edit `inbox.md` (fast capture)
* **`et`** — Edit main task files (`oneoffs.md`, `projects.md`, `tags.md`)
* **`eo`** — Edit backlog task files (`tomorrow.md`, `someday.md`, `waiting.md`)
* **`ea`** — Edit all active task files in split editor panes
