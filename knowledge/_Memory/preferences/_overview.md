# Assistant Preferences & Working Conventions

## Communication Style
- **Tone**: Concise, terse, professional, direct.
- **Formatting**: Plain text, Markdown with `file://` clickable links. Zero emojis.
- **Decision Making**: Explain, propose, and confirm before modifying files or executing multi-step workflows.

## Tool Integrations
- Preferred Editor: `$EDITOR` (Helix / Neovim / Nano / VSCode)
- Terminal Shell: Bash / Zsh / PowerShell
- Search Tool: `rg` (ripgrep)
