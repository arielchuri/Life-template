# Daily Routine

## Morning
- [ ] Hydrate and light movement
- [ ] Review today's schedule and punch list (`task`)
- [ ] Identify top 1–3 focus actions for the day

## Evening / Shutdown
- [ ] Process inbox tasks (`todo inbox` or `ei`)
- [ ] Update chronological log in `logs/`
- [ ] Stage tomorrow's priority tasks (`tomorrow.md` / `today.md`)
